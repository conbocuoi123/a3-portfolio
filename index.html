Kỹ năng chuyên môn

Tổng hợp nền tảng phát triển web tĩnh, quy trình quản lý mã nguồn và phần cứng/IoT cơ bản.

Phát triển Web (HTML5 & CSS3)

  • Cấu trúc HTML5 ngữ nghĩa, biểu mẫu và ràng buộc dữ liệu cơ bản
  • Bố cục CSS Box Model, Flexbox, CSS Grid và thiết kế Mobile-First
  • Trạng thái tương tác (:hover, :focus-visible, transition)

Công cụ & Quản lý mã nguồn

  • Làm việc với Visual Studio Code và DevTools (Elements, Network, Computed)
  • Quản lý phiên bản, commit, gắn tag và triển khai trên GitHub Pages
  • Viết tài liệu hướng dẫn và nhật ký kiểm thử rõ ràng

Nhúng & IoT cơ bản

  • Lập trình vi điều khiển ESP32 và kết nối cảm biến môi trường/độ ẩm đất
  • Điều khiển cơ cấu chấp hành qua relay và giám sát trên nền tảng di động
